# Line-following-robot
# Required Hardwares:
1.1x Arduino UNO R3
2.1x L293D Motor Drive Shield
3.QTR 8 Infrared Sensor
4.2x Wheel and Gear Motor
5.3 in 1 Jumper Wire
6.2WD Robot Car Chassis Kit
7.Arduino Compatible SCM & DIY Kits

# How to use
Burn the code into arduino and make connection according to the code or just make your connection and change the pin number in the code
