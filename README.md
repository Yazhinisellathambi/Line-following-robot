# Line-following-robot
# Required Hardwares:
 1x Arduino UNO R3
 1x L293D Motor Drive Shield
 QTR 8 Infrared Senso
 2x Wheel and Gear Motor
 3 in 1 Jumper Wire
 2WD Robot Car Chassis Kit
 Arduino Compatible SCM & DIY Kits

# How to use
Burn the code into arduino and make connection according to the code or just make your connection and change the pin number in the code
